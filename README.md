## Project Description
A web application for managing a product catalog built with Python Flask and SQLite.
The app supports full CRUD operations — add, view, edit, and delete products.
Additional features include search by name/description, filtering by category
and price range, sorting, and a live statistics dashboard.

## How to Run
```bash
pip install -r requirements.txt
python app.py
```
Open in browser: http://127.0.0.1:5000
